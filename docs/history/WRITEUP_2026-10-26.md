## Summary
- **Task.** Ectopic heartbeats must be flagged for a patient the model has never seen.
- **Data.** The MIT-BIH Arrhythmia Database, with the standard inter-patient split, made strictly subject-disjoint.
- **Design.** We compare a 10-qubit quantum reservoir (a fixed, untrained quantum dynamical system whose measured correlations are the features) with a classical echo state network. The two arms match on input encoding, readout size, readout model and tuning budget.
- **Headline.** On the pre-registered test split the quantum-reservoir arm scores macro-F1 0.727 and the classical arm 0.707: +0.021, 95% CI [-0.016, +0.062]. Under the pre-registered rule this is *no detectable change*.
- **Ventricular beats.** In the pre-declared slice family, the gain on ventricular-beat F1 is favorable: +0.069 [+0.021, +0.154]. It comes from halving false ventricular alarms.
- **Attribution.** Two controls isolate what is quantum:
  - a classical mean-field simulation of the same circuit matches the quantum arm (+0.004 [-0.003, +0.012]);
  - removing the circuit's couplings loses the ventricular gain.
- **Conclusion.** The improvement comes from the coupled spin-model feature map, which a classical computer reproduces. It does not come from entanglement or other quantum correlations. We report a quantum-circuit-*inspired* feature that beats a matched classical reservoir on one clinically relevant class, together with evidence that it is not a quantum advantage.

## 1. The healthcare problem
- **Users and setting.** Holter and wearable ECG monitoring records about 100,000 beats a day per patient. A technician or cardiologist reviews the beats the software flags as ectopic:
  - supraventricular ectopic beats (S, from the atria);
  - ventricular ectopic beats (V, from the ventricles).
- **Two costs.** A missed ectopic beat can hide an arrhythmia. A false flag adds review time.
- **Limitation of current models.** A model trained on other patients must work on a new patient without any of that patient's labels. This cross-patient (inter-patient) setting is hard: published inter-patient S-beat positive predictivity is typically 35-50% (`PROBLEM_BRIEF.md`, "Problem selection").
- **A common flaw in published work.** Many published quantum-ML ECG results use beat-level random splits. These put beats of the same patient in both training and test, so the reported accuracy measures within-patient recognition, not generalisation to a new patient.
- **Data.** MIT-BIH Arrhythmia Database (Moody & Mark 2001; PhysioNet, Goldberger et al. 2000; ODC-By 1.0):
  - 48 half-hour two-lead recordings from 47 subjects, each beat annotated independently by two or more cardiologists;
  - beats mapped to the AAMI classes N, S, V, F and Q;
  - the classification task uses N, S and V.
- **Split.**
  - The standard de Chazal inter-patient split: DS1 has 22 training records and DS2 has 22 test records (de Chazal et al. 2004, doi:10.1109/tbme.2004.827359).
  - We removed record 202 from the test set, because it comes from the same subject as training record 201 (A004).
  - The resulting primary test split, *ds2s*, has 21 records and 47,129 N/S/V beats.
- **External confirmation set.** The MIT-BIH Supraventricular Arrhythmia Database (SVDB; 78 records, 184,286 beats) is held back for a single, access-logged confirmation.
- **Intended outcome.** Higher macro-F1 over N/S/V on patients never seen in training, together with the review burden the user would experience.

## 2. The classical baseline (R0)
- **Model.** A leaky-tanh echo state network (ESN; Jaeger 2001): a fixed random recurrent network whose states feed a trained linear readout. It is the natural classical counterpart of a quantum reservoir:
  - both are fixed dynamical systems;
  - in both, only the readout is trained.
- **Shared pipeline** (identical in both arms; declarations in `EXPERIMENTS.md`, made before any tuning run):
  - **Beat window.** MLII lead, selected by name: -0.25 s to +0.45 s around each beat, averaged into 40 bins and standardised.
  - **Patient-relative input.** The window minus the element-wise median of the same patient's previous 32 beats. This is computed online from past beats only and needs no labels. On DS1 it recovered most of the accuracy that raw morphology loses across patients (E001, A009).
  - **Reservoir input.** Fed as 4 steps of 10 samples.
  - **RR block.** 8 shared rhythm features, appended in both arms: pre-RR, post-RR, local averages and their log-ratios, and relative amplitude.
  - **Readout.** Standardised [220 reservoir features | 8 RR features], then class-balanced multinomial logistic regression with L2. The L2 weight comes from the grid {0.001, 0.01, 0.1, 1}; the decision is the argmax.
- **Tuning.**
  - 30 configurations drawn at random from a declared search space: size, spectral radius, leak, input scale, density, bias.
  - Each is scored by out-of-fold macro-F1 on DS1 only, over 5 fixed record folds.
  - The ESN keeps the first 55 units after each of the 4 steps, so 220 features.
- **Selected configuration.** Size 55, spectral radius 0.68, leak 0.10, λ = 0.001.
- **Performance on ds2s** (5 seeds; E002):
  - macro-F1 **0.707**;
  - V: sensitivity 0.953, PPV 0.697;
  - S: sensitivity 0.595, PPV 0.269.
- **Verification.** R0 was verified for validity in a separate verification: V004 PASS. The reviewer reproduced every scored prediction file byte for byte from a clean environment.

## 3. The quantum contribution
- **Why a quantum reservoir.** The limitation we target is cross-patient generalisation of a training-free feature map. A quantum reservoir is a fixed physical dynamical system:
  - it needs no gradient training on the quantum side, so it avoids barren plateaus and costly parameter-shift training;
  - only the same linear readout is fitted to the training patients;
  - a hardware run needs only a forward pass per beat.
- **Why a matched classical reservoir.** The prior evidence is sceptical, so the comparison has to be strict:
  - in the largest careful benchmark, classical baselines won, and circuits without entanglement matched entangled ones (Bowles, Ahmed & Schuld 2024, doi:10.48550/arxiv.2403.07059);
  - with matched size and tuning effort, quantum reservoirs lose their edge (Pandey 2026, doi:10.48550/arxiv.2607.09905; abstract only).
  - So we match the classical reservoir on encoding, readout size, readout model and tuning budget, following the matching rule of Kornjača et al. 2024 (doi:10.48550/arxiv.2407.02553).
- **Gap.** We found no quantum reservoir study on MIT-BIH that uses an inter-patient split and a matched classical reservoir.
- **Circuit** (`src/qhc/pipe/reservoirs.py`, class `QRC`): 10 qubits, starting in |0...0>. For each of the 4 input steps:
  1. Encode the step's 10 samples as single-qubit RY rotations (angle = input scale x sample), applied to the current state (data re-uploading).
  2. Apply `depth` layers, each of:
     - ZZ couplings exp(-i Σ J_qr Z_q Z_r) on a chain or ring; the couplings carry fixed random disorder;
     - a transverse-field RX(h) on every qubit.
  3. Read out in the Z basis: the 10 ⟨Z_q⟩ and the 45 ⟨Z_q Z_r⟩, estimated from 1,024 shots.
- **Feature count.** 4 steps x 55 = **220 features**, exactly the ESN's count.
- **On hardware.** Each beat needs 4 circuits (one per readout step) of at most 10 qubits.
- **Simulation.** A GPU statevector simulator in PyTorch. It matches an independent dense-matrix implementation to 4e-7, and its finite-shot sampling is batch-invariant.
- **Tuning.** The same budget as the ESN: 30 configurations of input scale, J, h, depth, topology and disorder, on DS1 only.
- **Selected configuration** (E003):
  - input scale 0.317, J 0.106, h 0.159, depth 2, ring, disorder 0.42, λ = 0.1;
  - the couplings are weak, so the state stays close to a product state.
- **Two controls** isolate what is quantum. Both reuse E003's selected configuration, with no tuning of their own (EVAL.md rule 7):
  - **Mean-field model (E004).** The same gates on product states: each qubit's Bloch vector, with ZZ replaced by Z rotations driven by the neighbours' ⟨Z⟩, and the same 1,024-shot sampling. A classical computer evaluates this in linear time. If entanglement mattered, this control would score lower.
  - **Separable circuit (E005).** The same circuit with J = 0, so no couplings and no entanglement.

## 4. Fair evaluation
- **Pre-registration.** The evaluation was pre-registered before any model existed (`EVAL.md`): author-approved version EV1, then EV2, which added guard fixes only; scorer, units, metric and split are unchanged.
- **Metric.** Macro-F1 over N/S/V on ds2s, pooled over beats, averaged over 5 seeds per arm.
- **Uncertainty.** A paired two-level bootstrap: records resampled, then seeds; 8,000 replicates. It accounts for beats within a patient being correlated.
- **Decision rule for the headline** (fixed in advance). The rule is *favorable* only if all three hold:
  - delta ≥ +0.02;
  - the 95% CI lower bound is > 0;
  - the delta stays > 0 without record 232.
- **Slice family.** Four pre-declared members, tested at 98.75% (Bonferroni):
  - S-F1 and V-F1;
  - refitting on 5 and on 11 training patients.
- **Secondary metrics** (reported for every arm; none sets the outcome): de Chazal's VEB and SVEB measures, AUPRC, and review burden per hour.
- **Access rules.**
  - Training and tuning used DS1 only.
  - Every test-split access is logged (`runs/full_eval_log.jsonl`), and the command enforces the pre-registered order.
  - 7 of the 15 permitted test-split scorings have been used, the headline among them.
  - SVDB has not been opened for scoring.
- **Lookahead check.** Every arm passed a full-pipeline lookahead check: replacing a beat's future signal leaves its prediction unchanged (731 DS1 beats).

- **Where the gain comes from** (A015):
  - **V class.** The QRC arm halves false ventricular alarms (709 vs 1,324 per seed) and keeps the same ventricular sensitivity (0.949 vs 0.953). V PPV is 0.811 vs 0.697.
  - **S class.** The QRC arm is more conservative: fewer false S flags, but fewer S beats found. 288 of the 310 lost S detections are in record 232.
  - **Leave-one-record-out.** The headline delta is positive whichever test record is left out (+0.011 to +0.046).
- **Review burden per hour of recording**, QRC vs ESN:
  - 608 vs 806 S-or-V flags;
  - 217 vs 374 normal beats flagged;
  - 93 vs 57 missed ectopic beats.
  - The QRC arm flags 198 fewer beats per hour, 157 of them normal beats, at the cost of 36 more missed ectopic beats per hour, mostly S beats in one patient.
- **What is quantum** (A016):
  - The mean-field model reproduces the QRC to within +0.004 overall, and exactly on V-F1.
  - Removing the couplings costs V-F1.
  - So the ventricular gain comes from coupled spin dynamics as a feature map, and classical couplings suffice. This agrees with Bowles et al. 2024 and with the weak couplings the tuner chose.
- **Fairness checks.**
  - The ESN's selected λ sat at the edge of the declared grid. Extending the grid to 1e-5 changes neither arm's selection, so the predictions are byte-identical (E010, E011; A010 resolved).
  - On DS1 the QRC features give fewer false V flags than the ESN at every λ of the grid, so the V difference is not a regularisation artefact (E009, diagnostic).
  - On the S side, much of the difference comes from the QRC's stronger selected λ.

## 6. Limitations
1. **No quantum advantage (A016).** A classical mean-field simulation of the same circuit matches the quantum reservoir. The claim is a quantum-circuit-inspired feature map, not a quantum speed-up or an accuracy gain from entanglement.
2. **Headline not significant.** The overall macro-F1 delta is no detectable change. Only the V-F1 slice is favorable, and it is one of four pre-declared slice members.
3. **One patient dominates the S class (A001).**
   - Record 232 holds 75% of the test-set S beats, so S-class metrics on this split largely measure one patient.
   - The QRC arm's S loss is concentrated there.
   - We report the delta without 232 (+0.046) and the leave-one-record-out table.
4. **The standard split is not subject-disjoint (A004).**
   - Records 201 (training) and 202 (test) come from the same subject.
   - We removed 202 from the primary test split. The published 22-record DS2 is kept only as a secondary split, for literature comparison.
5. **Absolute S performance is low in both arms.** S PPV is 0.27-0.30, below the 35-50% typical of dedicated inter-patient classifiers. This study is a controlled quantum-vs-classical comparison, not a state-of-the-art arrhythmia classifier. No strong published classical model was rebuilt as a reference.
6. **Simulation only so far.** No device noise or hardware result yet (Phase 4).
7. **One classical model family.** The matched baseline is an ESN with a declared search space of 30 configurations. Another classical reservoir or a tuned non-reservoir model might do better on the same features.
8. **An incident with the confirmation set, before any model existed (2026-10-26 ~17:45 UAE).**
   - What happened: while a test of the confirmation guard ran, a path-binding bug made the code open the real SVDB label file.
   - What it exposed: the run failed on beat-ID validation before any metric was computed. The only output was an error giving the size of the prediction set and one beat ID, both already public in the released positions file.
   - What it did not expose: no label values or scores were displayed or stored.
   - Review: the bug was fixed, the guard test now asserts that the real file is never opened, and the reviewer (V002) judged that SVDB is not compromised as a confirmation set (`EVAL.md`, access log).
9. **Smaller points.**
   - The tuning scores were computed with float32 code before a float64 switch made the outputs batch-invariant (A011). Retuning in float64 selects the same configurations.
   - Current MIT-BIH annotation totals differ from de Chazal's Table II by at most 2 beats per class (A008).
   - SVDB headers carry no demographics, so subject overlap with MIT-BIH cannot be checked (A006).
